# Ring Racers UWP (Zebulan Edition)

> [!IMPORTANT]
> **This project has moved to [ZebulanStanphill/RingRacers](https://github.com/ZebulanStanphill/RingRacers).** The Xbox app is now built from the same repository as the engine it used to pin as a submodule. This repository is archived and no longer updated.

This was the home of an unofficial UWP port of [Dr. Robotnik's Ring Racers](https://github.com/KartKrewDev/RingRacers) v2.4 for Xbox One and Xbox Series consoles in Dev Mode. It is not a Kart Krew Dev project, so don't report bugs to them.

This repository's history was carried over with its files moved under `uwp/`, so every commit and its author is in the new repository too, under a new hash. The commits here keep their original hashes, and the files below are as they were at the move.
