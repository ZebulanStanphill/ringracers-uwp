# Changes from Ring Racers v2.4

Changes from vanilla [Ring Racers v2.4](https://github.com/KartKrewDev/RingRacers/releases/tag/v2.4). Engine changes live in `patches/ringracers-uwp.patch`; SDL changes live in `patches/sdl-angle.patch` and `patches/sdl-controller-duplicates.patch`; `uwp/` and `build.ps1` provide the launcher and build.

Unless stated otherwise, changes apply only to UWP builds (`SRB2_CONFIG_UWP`, which defines `_UWP`). The GL2 RHI's general call reductions and OpenGL ES support, colormap caching, most Software optimizations, UDP error handling, Lua userdata set, state bookkeeping, and interpolation-list changes apply to every platform built from the patched source. Individual Legacy GL entries identify other shared changes.

Game logic results are unchanged. Optimizations do the same work in less time, preserving replay, netplay, and ghost behavior. Status markers mean *(works on Xbox)* or *(untested on Xbox)*; qualifiers identify partial coverage. Confirmation refers to Xbox One X, including features confirmed before the driver replacement and carried forward unchanged. Build, CI, and tools have no Xbox marker.

## Platform and build

- **UWP library and launcher.** `SRB2_CONFIG_UWP` and the `ninja-x64_windows_uwp_vcpkg-release` preset build a static game library without a Git revision suffix in its executable name. The launcher starts it through `SDL_WinRTRunApp`, caches the CoreWindow on the UI thread, and reports the process memory budget; this builds on [worleydl's port](https://github.com/worleydl/ringracers-uwp), rebased onto v2.4.
- **Dependencies and CPU.** SDL2 and libuwp come from [worleydl/uwp-dep](https://github.com/worleydl/uwp-dep). The game targets Xbox One's Jaguar CPU with `-march=btver2`, also supported by Xbox Series X|S; Jaguar has no FMA, preserving the floating-point behavior of other x64 builds.
- **Package.** The manifest version is 2.4.0.0 and requests file system, removable storage, network, expanded resources, and microphone access for voice chat. Runtime DLLs are not copied beside the static library.
- **Audio** *(works on Xbox)*. The audio driver is WASAPI instead of DirectSound.
- **Build script.** `build.ps1` clones v2.4, applies the patches, builds SDL2 and the game, verifies ANGLE's download with SHA-256, and generates the launcher solution.
- **CI.** Linux builds 52 native regression tests with four workers and runs them with ASan/UBSan; the Windows `warp` job compiles 97 translated add-on shader stages for Shader Model 5.1 and runs the Direct3D 12 WARP harness with the debug layer and GPU-based validation. Negative controls run one process per core with the debug layer, and shader-mutant controls check the shader oracles; [tests/README.md](tests/README.md) describes coverage and limits.
- **Build artifacts.** The separate `build` job runs alongside the tests and uploads a sideloadable `.msix` signed with a throwaway certificate, its certificate, and the linker map (`ringracers-uwp-symbols`); a test failure still fails the workflow. Actions use Node.js 24 releases, and Visual Studio's Developer PowerShell exports the x64 environment to later steps.
- **Shader smoke test.** The [installable PK3](tests/addons/shader-smoke/README.md), uploaded as `shader-smoke-test`, supplies shader-only checker and water-ripple effects without gameplay scripts or replacement assets.

## VibeRant D3D renderer

### Direct3D 12 driver

- **Renderer and default** *(works on Xbox)*. VibeRant D3D draws upstream Legacy GL through `src/hardware/r_d3d12/` and is the default for new configs; valid saved renderer choices remain effective. Startup logs `UWP: VibeRant backend: D3D12`, and a failed driver start falls back to Software.
- **Shaders** *(works on Xbox)*. `fxc` compiles the built-in HLSL at build time for Shader Model 5.1 with an embedded root signature. Xbox One X exposes feature level 12_0 and Shader Model 5.1; Xbox One has no Shader Model 6.
- **Presentation** *(works on Xbox)*. The driver copies frames into four presentation textures for ANGLE, which owns the window: sharing paths A, B, and C are tried before readback path D. Shared presentation normally shows the previous frame, wipes show the current frame immediately, and textures are not reused until ANGLE finishes reading them.
- **GPU synchronization** *(works on Xbox)*. Where available, shared fences let ANGLE wait for the frame copy and the Direct3D 12 queue wait for ANGLE's last read on the GPU; fence failures fall back to CPU waits, as does readback. The 2026-10-16 Xbox log confirms `interop path A, sync shared fences` with no `ANGLE read waits`; see the presentation setting below.
- **Resources and constants** *(works on Xbox; 3D models and mipmaps untested)*. Drawing constants use a root-CBV ring, and fence completion controls resource and descriptor reuse, resizing, and shutdown. Models, indices, and sky buffers use persistently mapped 4 MB upload arenas; the driver generates RGBA8 mip chains on the CPU and skips redundant topology, stencil-reference, and viewport changes.
- **Texture heaps** *(works on Xbox)*. Textures use shared 16 MB heaps with 4 KB or 64 KB alignment, quarter-octave size classes, and a 4 KB guard after each reported allocation; textures exceeding the 4 MB class limit including the guard, or failing placement, get a dedicated heap with a spare 64 KB page. Committed textures remain a logged last resort: the guards protect against Xbox One's resource-state word corrupting neighboring or final texels, and the 2026-10-16 Xbox log shows dedicated heaps with zero committed textures; see [texture placement](docs/d3d12-texture-placement.md).
- **Pipeline prewarming** *(works on Xbox)*. One worker prewarms 36 built-in shader pairings without blocking draws. `UWP D3D12: prewarmed` and the first 64 main-thread `PSO #` cache misses report creation cost.
- **Add-on shaders** *(works on Xbox)*. Pinned glslang and SPIRV-Cross translate `SHADERS` GLSL into Shader Model 5.1 HLSL for polygon, sky, and model layouts; `D3DCompile` compiles it, and load-time pipeline validation rejects invalid programs in favor of built-ins. Missing stages use shared built-in GLSL, Ignore custom shaders keeps built-ins, and custom sprite stages also cover clipped sprites; compiler notices ship in `Licenses`.
- **Custom water and shader limits** *(works on Xbox)*. Custom water color keeps built-in refraction through a composite variant; a custom vertex stage requires a whole-viewport capture, while capture/variant failure or Reduce VFX uses normal blending without refraction. Underwater/heat postprocessing stays built-in, arbitrary uniforms use their initializer or zero without engine setters, and uninitialized uniform arrays and extra vertex attributes remain unsupported; see [add-on shader notes](docs/d3d12-custom-shaders.md).

### Matching Software

- **Palette rendering** *(works on Xbox)*. Ported from SRB2, palette rendering lights surfaces through colormaps, limits colors to the palette, and applies palette flashes and the color profile to the whole frame. It rebuilds cached textures when Encore's remap changes, preventing colors from the previous normal/Encore race from carrying over; without palette rendering, flashes remain white or pink overlays.
- **Brightmaps** *(untested on Xbox)*. Brightmapped pixels use the base colormap's full-bright row rather than a sector's tint/fade, in palette and smooth rendering, while retaining Encore's texel remap. SPRTINFO sprite brightmaps include roll rotation with the base patch's transform, pivot, flip, and origin; missing or differently sized maps fall back to ordinary lighting, and cache reloads/purges release rotated companions. Sprite brightmap selection and rotated companions apply to every patched platform.
- **Springs** *(works on Xbox)*. Springs use Software's origin and sprite-height sorting against solid walls, two-sided upper/lower walls, and opaque 3D floor sides and planes, including nearer faces drawn over them. Clipping removes rounding slivers and clamps crossed sprite light slices to prevent bow-ties, hiding Metropolis's springs inside bumpers without dashes; ordinary sprites and translucent or see-through sides retain per-pixel depth behavior.
  - **Clipping bounds** *(untested on Xbox)*. Capacity checks prevent spring and near-plane clipping from overrunning buffers; an oversized silhouette is ignored or its affected triangle remains whole, so a rare spring sliver can remain visible.
- **Water** *(works on Xbox; split-screen and other overlapping-volume cases untested)*. Translucent ripple surfaces refract the scene behind them. Unlike Software, which distorts only the background, this also refracts visible submerged geometry. It uses Software's wave timing, distance attenuation, and signed pixel rounding with viewport clamps and six blend modes. Coplanar pieces share an immutable, bounded capture expanded by disjoint strips and a 16-pixel ripple margin; intervening draws, different layers/slopes, or polyobjects start fresh captures, and the shared-platform `FOF_CUTEXTRA` rule removes hidden internal water/fog boundaries as Software does, retaining touching or different-kind boundaries.
  - **Water fallbacks** *(works on Xbox)*. Offscreen faces need no copy, near-plane crossings use conservative full-view bounds, and standalone polyobjects use bounded per-face captures. Reduce VFX disables distortion, opaque ripple surfaces keep texture-only ripples, and capture failure retains ordinary rendering; controlled Xbox performance comparisons remain pending.
- **Underwater and heat distortion** *(works on Xbox; split-screen untested)*. Per-pixel sampling follows Software's wave shapes and tic timing rather than Legacy GL's coarse grid; underwater displacement reaches 1% of the full frame width, and sampling clamps to each viewport without affecting the HUD. Reduce VFX disables both effects, and desktop OpenGL retains its grid and single-view limit.
- **Fog** *(untested on Xbox)*. With Shaders on, fog walls and planes remap the captured scene inside colored, inward, outward, and overlapping boundaries, using Software's integer light rows and control colormaps in palette mode or tint/fade equations in smooth mode. Each visible face copies its projected bounds into one retained RGBA texture, preserving portal/viewport clipping without depth writes; custom fog shaders own their output, and allocation failure uses the old shader.
  - **Fog approximation** *(works on Xbox)*. Shaders Off and desktop OpenGL retain one cached inward neutral camera-fog approximation: cap surface light, apply the colormap and sky attenuation once, and omit that block's boundary polygons. This shared-platform path needs no scene copies but can differ from Software in color, brightness, and boundary placement; colored, outward, and overlapping fog retain older paths.
- **Palette fades and wipes** *(works on Xbox)*. Palette Rendering uses Software's fade-map rows before the HUD, clamps strength to the available rows, and leaves flashes/color correction to the final palette pass; missing resources or Palette Rendering Off use the overlay (`path=exact` or `path=overlay`). Transitions support black/white Mega Drive-style fades, inversion, Encore wiggle, and reversed fades, with the final current frame shown immediately; an unavailable full wipe falls back to two passes.
- **Encore inversion flag** *(untested on Xbox)*. `PF_Invert` has a separate bit from depth writes so blend selection recognizes screen inversion instead of drawing a white quad.
- **Portals** *(works on Xbox)*. Special-40 linedefs show their paired destination through stencil openings and exit-plane clipping, using Software's tag pairing, rotation, and floor-height offset; the approach credits [SRB2Kart Saturn](https://github.com/Indev450/SRB2Kart-Saturn). `maxportals` defaults to 2, with 0 disabling portals; recursive views use the regular sky, maps without portals skip the search, and the player model can disappear near an opening as in Software.
- **Sky alignment and horizon boundaries** *(works on Xbox)*. Sky domes and the flat fallback honor single-patch header offsets, and empty two-sided sky boundaries no longer extend opaque floors over the background, fixing Water Palace's sky position and cutoff. The horizon check applies on every patched platform; real boundaries still extend, and signed sky offsets use multiplication instead of undefined negative left shifts.
- **Skybox visibility** *(untested on Xbox)*. Precipitation and things marked `RF_HIDEINSKYBOX` are excluded from skybox views on every patched platform.

### Fixes to Legacy GL

- **Wall light slices** *(works on Xbox; split-screen untested)*. UWP clips each lighting band to its original wall and splits crossing slopes, preserving UVs, lighting, alpha, and solid-floor holes. This removes inverted slices that covered Water Palace scenery with brown wall pixels, without new GPU resources or copies.
- **Missing floors and ceilings** *(works on Xbox)*. BSP cuts send unsplit polygons to their actual side, and a closed GL-seg loop supplies a fallback for subsectors missing a polygon. This fixes reported holes on Green Hills Zone and Storm Rig on every patched platform; some inherited oversized subsector polygons remain possible.
- **Sprite-textured models** *(untested on Xbox)*. Every patched platform prepares a model's selected sprite patch before reading hardware data and compares sprite dimensions when refitting UVs, preventing crashes with models such as item boxes after video changes.
- **Title background lighting** *(untested on Xbox)*. Preparing neighboring 3D-floor lighting before use prevents a briefly lit title-map background during fade-in on every patched platform.
- **Fill transparency** *(untested on Xbox)*. Every patched hardware renderer honors fill translucency and HUD fades, including the spectator Watching underline over the finish-grade icon. Opaque fullscreen fills retain the clear shortcut; translucent fills blend over the full surface.
- **Polyobject ripples** *(untested on Xbox)*. Moving floors and ceilings use their control sector's ripple flag, including translucent planes, on every patched platform. Regular and polyobject planes honor Reduce VFX when selecting ripples.
- **Raw pictures** *(untested on Xbox)*. Every patched platform supports opaque intensity/grayscale and RGB24 pictures alongside palette, intensity/alpha, and RGBA modes, including nearest-neighbor resizing. Conversion validates headers, dimensions, modes, and lengths, ignores trailing bytes, and prevents RGBA destination overruns.

### Settings

- **Advanced menu** *(works on Xbox)*. The renderer list says **VibeRant D3D**. Options → Video → Advanced describes it as a Direct3D 12 port of Legacy GL with 3D models, true perspective and closer Software parity, notes that some features are missing or degraded, and asks for visual bugs to be reported to GitHub.com/ZebulanStanphill/ringracers-uwp. Switching to it shows no confirmation or loading warning, and its **VibeRant D3D Options...** section has no blank rows.
- **Palette control** *(works on Xbox)*. `gr_paletterendering` defaults to On and requires Shaders on.
- **Better transparency ordering** *(untested on Xbox)*. Saved `gr_bettertransparency` defaults to Off on every patched hardware-renderer platform; On inserts blended sprites, models, linkdraw attachments, and always-on-top sprites into the transparent surface pass using overlap, depth, and plane-side checks. It adds per-view CPU sorting and storage without scene copies, preserves opaque depth drawing and water-capture runs, and works with Shaders on or off; proxy model bounds, unsplit face crossings, cyclic intersections, and triangles within translucent models limit accuracy.
- **Batching** *(works on Xbox)*. `gr_batching` defaults to On, resets at launch, and appears directly below Better transparency ordering for controller access.
- **Presentation control** *(works on Xbox; Readback and CpuSync untested)*. Saved, console-only `gr_d3d12_present` offers Auto (default), Readback (force path D), and CpuSync (keep CPU waits on shared paths). Restart after changing it; [diagnostics notes](docs/d3d12-diagnostics.md) describe its logs and fallbacks.

## Software renderer and GL2 RHI

- **ANGLE/OpenGL ES 2** *(works on Xbox)*. ANGLE runs the RHI and presents VibeRant D3D frames through its Direct3D 11 device, replacing worleydl's desktop OpenGL/Mesa path. The GL2 RHI supports ES 2 contexts, GLSL ES 1.00, core framebuffer entry points, `glClearDepthf`, unsized texture formats, RGBA screenshot readback, and no `glReadBuffer`; `patches/sdl-angle.patch` builds SDL with EGL/ES 2.
- **Display** *(works on Xbox)*. libuwp supplies display size and refresh rate, while rendering uses ANGLE's surface size, which may be smaller than the HDMI mode. The window stays fullscreen, fixing the tiny loading screen.
- **Encore distortion** *(untested on Xbox)*. Encore mirroring combines with underwater and heat distortion instead of replacing them in Software and Legacy GL on every patched platform.

## Network

- **Unreachable UDP routes** *(untested on Xbox)*. Host-unreachable and network-unreachable sends, including Winsock 10065, count as dropped packets on every patched platform. Existing retries and timeouts decide recovery; other unexpected send errors remain fatal.
- **Online loading** *(works on Xbox)*. UWP VibeRant clients send basic keepalives during geometry/resource loading and vanilla tic acknowledgments at most once per clock tic while connected in-game, excluding demos and savegame redownloads. This prevents loading-related delay kicks without changing server delay rules or the receive limit; a kick logs the last reported delay/limit and local simulated, received, and level tics.
- **Track title timing** *(works on Xbox)*. Pre-race titles start with a fresh clock after loading and retain upstream animation steps and HUD timer clamps. Online VibeRant clients animate the title in the normal HUD while simulation catches up; hosts, Software, offline play, and demos retain the pre-level animation.

## Files and startup

- **Data and logs** *(works on Xbox)*. Assets use `E:\ringracers`; config and saves use `E:\ringracers\ringracers`, ignoring `-home` and `RINGRACERSWADDIR`. The save folder exists before the writability check. The log uses `E:\ringracers\latest-log.txt` because the package directory is read-only.
- **Background file check** *(untested on Xbox)*. Main files load with expected MD5s while a below-normal-priority worker verifies contents in 1 MB reads; zip local headers wait until an entry is used. B skips checking without a prompt, startup waits before network setup if needed, and mismatches raise the usual error at the next loading step or final wait; logs record per-file time/speed, outcome, and wait.
- **Music and sound hashes** *(untested on Xbox)*. Files without expected MD5s hash their names rather than contents for duplicate detection. They are not transferred to netgames or recorded in replays.
- **Direct3D 12 launch check** *(works on Xbox)*. Launch requires a hardware adapter that creates a feature-level-11_0 Direct3D 12 device and command queue, excluding software adapters and Basic Render Driver. Failure shows a Dev Home Game-type pop-up, flushes logs, and exits; the launcher links `d3d12.lib`/`dxgi.lib`, and `expandedResources` can provide game resources even with App selected.
- **Earlier loading text** *(untested on Xbox)*. Graphics, fonts, and console initialize before map thumbnails/minimaps; **Loading maps...** redraws up to ten times a second, keeping the file-check skip text visible.
- **Loading-to-intro transition** *(works on Xbox)*. The intro starts with the credits card instead of six blue tics, without changing timing. VibeRant D3D skips clear-only presentation before its first drawn frame, keeping the loading screen visible instead of flashing black.

## Performance

### Rendering

- **Level precaching** *(works on Xbox)*. Legacy GL warms walls, flats, brightmaps, FOF control sectors, existing models, and current player models/colors during loading, then repeats player warming after spawning and hooks. Dedicated servers, reloads, snapshots, and rewind skip it; sprite-textured models, future animation frames, later objects, and view-dependent remaps remain lazy, and Models must be enabled for model warming.
- **Device-removal checks** *(untested on Xbox)*. Upload rings read a removal flag set by failed calls or fences instead of making a kernel query on every allocation. A full device check still runs once per frame.
- **Video memory safeguard** *(untested on Xbox)*. Exceeding the local budget schedules a texture-cache flush for the next frame, at most once every five seconds. Model buffers remain, but reloading textures can hitch.
- **GL2 call reduction** *(works on Xbox)*. Every patched platform skips redundant state/texture/buffer binds, disables only enabled vertex arrays, caches uniform locations, changes sampler uniforms only when needed, and retains framebuffers. Colormap/lighttable textures upload only after changes and expire after 300 unused frames; palettes upload only when changed and the default colormap once, while UWP uses `GL_RED` with `EXT_texture_rg` where available to avoid ANGLE's luminance conversion.

### Software renderer

- **Planes and sorting** *(works on Xbox)*. Every patched platform clears only visible visplane columns, skips draw nodes outside a sprite's columns before reading them, and computes 3D-floor plane bounds once during sorting.
- **Columns** *(works on Xbox)*. Every patched platform leaves unused thick-side slots alone, copies wall-column data only for remapping, computes masked clipping limits once, and passes read-only column data directly to drawers. UWP also inlines `R_GetTextureNum`.
- **Screen tilting** *(works on Xbox)*. Every patched platform steps along source rows instead of rebuilding a full-screen pixel map, preserving float stepping, clipping, zoom, and mirrored sampling. Large views share work across Software workers.

### Game logic

- **Arithmetic and references** *(works on Xbox)*. UWP inlines `FixedMul`, release-build `P_SetTarget`, and `P_MobjWasRemoved`, preserving collision callback reference order and `PARANOIA` checks.
- **Subsector cache** *(works on Xbox)*. UWP caches `R_PointInSubsector` results for 512 recent points and clears them when the BSP loads or is freed.
- **Lua userdata** *(works on Xbox)*. Every patched platform tracks pointers with Lua userdata, letting frees skip Lua when none exists.
- **State bookkeeping** *(works on Xbox)*. Every patched platform gives each `P_SetMobjState`/`P_SetPlayerMobjState` nesting depth its own table and clears only recorded states. Calls that remove an mobj balance the nesting count instead of making later calls look nested.
- **Interpolation list** *(works on Xbox)*. Every patched platform records each mobj's interpolation-list slot so removal needs no search.

### Frame pacing and threads

- **Pacing** *(works on Xbox)*. Frames skipped to catch up on simulation do not sleep; drawn frames still sleep to the cap with V-Sync and a matching-refresh cap, following worleydl's Xbox timing fix.
- **Thread pool** *(works on Xbox)*. The pool uses Xbox's allocated processor count, falling back to upstream's hardware count when no processors are marked.

## Diagnostics

- **Startup and performance logs** *(works on Xbox)*. Startup records graphics/device capabilities, surface size, shader compilation, first-frame steps, loading/asset times and logging cost, memory budgets, CPU sets, and thread-pool size. Every five seconds `UWP perf:` reports FPS, frame/tic and HUD/present times, draws/uploads/resources, mobj/collision/Lua activity, subsector-cache hits, main-thread CPUs, profiler pauses, and renderer/portal CPU and GPU costs.
- **Driver counters** *(works on Xbox)*. `UWP perf:   D3D12:` includes `per frame` constant updates (`root CBV ring`), `pipeline:`, `rings:`, `textures:`, `models`, `texture heaps:`, `palette:`, `screens:`, `water:`, `portals:`, and `present:` statistics. These identify pipeline creation, upload peaks/wraps/stalls, storage, lazy models/mips, screen/fog/water copies, and synchronization, including `GPU waits: copy N, read N`, `ANGLE read waits`, query timeouts, and fallback `glFinish` counts.
- **Spring probe** *(works on Xbox)*. `gr_springprobe` waits for the console to close, then logs one main-world view, excluding skybox/portal passes. `UWP spring probe camera:`, `UWP spring probe:`, `UWP spring entry:`, `UWP spring result:`, and `UWP spring probe end:` record camera/settings, sprite heights/quad/depth, wall/plane tests and cuts, remaining area, and piece limits without changing drawing.
- **Pixel history** *(untested on Xbox)*. `gr_surfaceprobe [x_percent y_percent]` defaults to `15 35` from the top-left and requires a level, hardware rendering, split-screen off, and Batching off; it captures after the console closes. `surface probe:` logs `begin`, changed-color `sample=` rows with source/texture/flags/shader/depth/alpha and up to eight vertices, and `end`; one 4 MB readback buffer holds up to 8,192 samples with 256 color-change reports and explicit overflow/omission counts, is released after the frame, and does no work while inactive. The requested frame stalls for readback and is unsuitable for benchmarking; see [Direct3D 12 diagnostics](docs/d3d12-diagnostics.md) for row formats and timeout logs.
- **Sky geometry trace** *(works on Xbox)*. `UWP sky geometry:` and `UWP sky surface:` log camera/settings and submitted `~015` floors, `GFZROCK`-referencing walls, and invisible occluders with source IDs and vertices, not proof of visible pixels or the placeholder's bound texture. Sampling excludes skybox/portal passes and caps each view at 16 floors, 16 walls, and four occluders once per five seconds; device overhead is unmeasured.
- **Frame, title, and fade traces** *(works on Xbox)*. `UWP frame:` records positions, camera, elapsed time, tics, interpolation, title timers, and copied/shown slot IDs during titles and level seconds 10–20, capped at 300 frames per window. `UWP: track title:` summarizes animation timing; `UWP fade:` records state/load/wipe/palette changes in ten-second, 200-event windows and caps title-map/light-fade samples at 20 each.
- **Memory and stalls** *(works on Xbox)*. Perf summaries include DXGI local budget/usage and tracked texture, buffer, ring, render-target, and presentation storage. `GPU frame exceeded 250 ms` logs once, while abandoned fence waits log at most once per second with suppressed warnings counted.
- **GPU failure details** *(untested on Xbox)*. Device removal and the first GPU-wait timeout dump DRED breadcrumbs when available, with page-fault details on removal. Search for `GPU wait for <what> timed out after N ms; breadcrumbs:` and `DRED:`.
- **Profiler and crashes** *(works on Xbox)*. `src/sdl/i_uwpprofile.cpp` samples the main thread about 50 times a second during play, writing stacks/activity to `E:\ringracers\uwp-profile.txt`. A vectored exception handler logs crashes and stacks because the app runtime bypasses the game's signal handler; it cannot catch stack-cookie termination.
- **Error dialog** *(works on Xbox)*. The short Xbox dialog contains the error plus visible drives and their `ringracers` folders, and saves the text to `E:\ringracers\error.txt`.
- **Tools.** `tools/` summarizes perf logs, resolves profile/crash addresses to functions, and annotates instructions with samples.

## Other fixes

- **Options button slide** *(works on Xbox)*. Submenu title buttons start their slide once and finish at or after the final tic, preventing repeated bouncing when low frame rates skip a menu tic.
- **Console slide** *(works on Xbox)*. On every patched platform, opening and closing use elapsed time since the last movement, keeping the intended speed through skipped frames and stalls.
- **Duplicate controllers** *(works on Xbox)*. `patches/sdl-controller-duplicates.patch` stops each controller from appearing twice, and each press from counting twice, in Game mode.

## Removed or disabled

- **Old hardware driver** *(untested on Xbox)*. The Direct3D 11 driver, Shader Model 4 built-ins/tests, and `gr_d3d12` Off/Once/On selector are removed; an old config line reports `Unknown command` once. A saved `renderer VibeRant D3D11` is rejected as an invalid value and keeps the VibeRant D3D default. The old sharing/shader probes no longer run, and VibeRant D3D replaces `r_opengl.c` only on UWP.
- **App-incompatible crash handlers.** DbgHelp minidumps, cpptrace, and `exchndl` are disabled for UWP; [Diagnostics](#diagnostics) describes their replacement.
- **Master server debug output.** Verbose `masterserver_debug` curl output and the Windows log-copy helper compile only with `LOGMESSAGES`, which defaults to on.
